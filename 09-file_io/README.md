# 09 - File I/O

Program ini mendemonstrasikan cara menulis dan membaca file sederhana.

## Cara Compile
```bash
nasm -f win64 main.asm -o main.obj
gcc main.obj -o main.exe
```

## Cara Menjalankan
```bash
.\main.exe
```

## Output Contoh
```
file berhasil ditulis.
isi file: halo dari orang hitam!
```
