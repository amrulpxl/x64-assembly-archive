# 10 - Proyek Akhir

Program ini merupakan mini proyek CRUD/menu interaktif sederhana berbasis Assembly.

## Cara Compile
```bash
nasm -f win64 main.asm -o main.obj
gcc main.obj -o main.exe
```

## Cara Menjalankan
```bash
.\main.exe
```

## Output Contoh
```
Menu:
1. Tambah Data
2. Lihat Data
3. Hapus Data
4. Keluar
Pilihan Anda: 2
Data saat ini:
1. Andi
2. Budi
```
