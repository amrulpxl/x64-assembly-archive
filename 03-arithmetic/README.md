# 03 - Aritmatika

Program ini melakukan operasi aritmatika dasar dan menampilkan hasilnya.

## Cara Compile
```bash
nasm -f win64 main.asm -o main.obj
gcc main.obj -o main.exe
```

## Cara Menjalankan
```bash
.\main.exe
```

## Output Contoh
```
penjumlahan: 15
pengurangan: 5
perkalian: 50
pembagian: 2
```
