# 02 - Variabel

Program ini mendemonstrasikan penggunaan variabel dan menampilkan nilainya.

## Cara Compile
```bash
nasm -f win64 main.asm -o main.obj
gcc main.obj -o main.exe
```

## Cara Menjalankan
```bash
.\main.exe
```

## Output Contoh
```
nilai variabel x adalah: 10
nilai variabel y adalah: 25
```
